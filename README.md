# Random Password Generator

## Project Overview

A Python program that generates random passwords based on the user's selected length and character types.

## Features

- Minimum password length of 8 characters.
- Lowercase and uppercase letters.
- Numbers and symbols.
- Requires at least two character types.
- Input validation.
- Option to generate another password.
- Secure random selection using Python's `secrets` module.

## Technologies Used

- Python 3
- VS Code

## How to Run

1. Install Python 3.
2. Open this project folder in VS Code.
3. Open the terminal.
4. Run `python main.py`.
5. Enter the desired length and character types.
